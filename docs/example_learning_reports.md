## What a Report Looks Like

Reports are generated by `LearningReportGenerator.generate_full_report()`.
The examples below show what the report will look like at various stages.

---

## Example A: Day 1 (No Data)

```
# Learning Report
Generated: 2026-03-28T00:00:00+00:00
Source: event_driven_runtime

## Trade Performance
  Total closed: 0
  Wins: 0  Losses: 0
  Win rate: N/A — Insufficient samples (0/30)

## Trader Calibration
  No calibration data yet.

## Setup Families
  No setup family data yet.

## Active Recommendations
  No recommendations generated.
```

This is correct behavior. No data → no conclusions.

## Report Interpretation Rules

1. **Never act on a single report alone.** Calibration can shift as more
   data accumulates.

2. **Source matters.** A report for `simplified_backtest` uses EMA-crossover
   signals only. Trader calibration data from this source is NOT valid
   for evaluating trader quality.

3. **Caution ≠ disable.** A caution recommendation means "flag for review",
   not "stop using this trader."

4. **Quarantine ≠ remove.** Quarantine means "escalate to human review."

5. **30-sample minimum is a floor, not a target.** 30 samples gives weak
   statistical power. 100+ samples provides meaningful conclusions.
